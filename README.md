# Forma — прототип интернет-магазина

Минималистичный адаптивный магазин на русском языке: каталог с категориями, корзина, форма заказа и вариант оплаты при получении.

## Как опубликовать через GitHub Pages
1. Распакуйте архив.
2. В репозитории `aktan9383-design/forma-store` нажмите **Add file → Upload files**.
3. Загрузите `index.html` из папки `forma_store` в корень репозитория и нажмите **Commit changes**.
4. Откройте **Settings → Pages**.
5. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и сохраните.
6. После публикации GitHub покажет адрес сайта в разделе Pages.

## Важно
Это только демонстрационный фронтенд. Корзина хранится в браузере, а заказы не отправляются продавцу и не сохраняются на сервере. Не используйте его для реальных заказов, пока не подключены серверная обработка, защищённая база данных, уведомления, политика конфиденциальности и меры защиты персональных данных. Оплата при получении указана как способ оплаты; никаких платежей сайт не обрабатывает.
